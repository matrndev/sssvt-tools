
# sssvt-tools

a better interface for my school's timetable, built on data scraped from the school website.

this project is still under development, more features to come.

[live demo](https://tools.matrn.dev)

companion project: [matrndev/sssvt-scraper](https://github.com/matrndev/sssvt-scraper) (the actual scraper, which pipes the data into a sql db for this app to read from)

## features

- comprehensive filtering of all timetables in two modes (easy, advanced)
- chip colors for groups 1-4, for easier orientation
- chip colors for computer rooms & home classrooms
- highlighting lessons of same subject on hover
- shows which other classes have lunch at the same period
- a vertical bar showing the current time in the timetable
- highlighted sub lessons
- mobile compatibility


## deployment
the app needs a postgresql database filled by [sssvt-scraper](https://github.com/matrndev/sssvt-scraper)

1. first, set up the scraper and let it populate the database
2. clone this repo and install dependencies (requires node 20.9+ and pnpm):
   ```bash
   pnpm install
   ```
3. create a `.env.local` file with your database connection string:
   ```
   DATABASE_URL=postgres://user:password@host:5432/database
   ```
4. build and start:
   ```bash
   pnpm build
   pnpm start
   ```

it can also be deployed like any other next.js app, as long as `DATABASE_URL` is set and the db is reachable.

for local development, run `pnpm dev`.
